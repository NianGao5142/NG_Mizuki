## 如何更换公共DNS

更换公共 DNS 是解决网页打开慢、视频卡顿以及你之前遇到的“DNS 请求超时”最直接有效的方法。

鉴于你之前遇到的网络问题，我强烈建议你**优先在路由器上修改**，这样家里所有的设备（手机、电脑、电视）都能同时受益，自动避开运营商默认的慢速 DNS。

以下是三种最常用的修改方法，请根据你的需求选择：

### 📋 准备工作：推荐的高速 DNS 地址

在设置前，请从下表选择一组你喜欢的 DNS 地址（国内用户首选阿里或腾讯，速度快且稳定）：

表格

|服务商|首选 DNS|备用 DNS|特点|
|---|---|---|---|
|**阿里 DNS**|**223.5.5.5**|**223.6.6.6**|国内速度极快，电商级稳定性，推荐首选|
|**腾讯 DNSPod**|**119.29.29.29**|**182.254.116.116**|对腾讯系业务（微信、游戏、B站）有优化|
|**114 DNS**|**114.114.114.114**|**114.114.115.115**|老牌公共 DNS，兼容性好|
|**百度 DNS**|**180.76.76.76**|-|百度用户推荐|

---

### 🛠️ 方法一：在路由器上修改（最推荐，全家生效）

这是“一劳永逸”的方法，修改后，连接该 Wi-Fi 的手机、平板、电脑都会自动使用新 DNS。

1. **登录路由器后台**：
    - 查看路由器背面的标签，找到管理地址（通常是 `192.168.1.1` 或 `192.168.0.1`）以及管理员账号密码。
    - 在浏览器地址栏输入该 IP 地址并回车，登录管理界面。
2. **找到 DNS 设置**：
    - 通常在 **“网络设置”**、**“WAN 口设置”** 或 **“DHCP 服务器”** 菜单下。
    - 找到 **“DNS 服务器”** 选项，将默认的“自动获取”改为 **“手动设置”**。
3. **填入地址并重启**：
    - 在“首选 DNS”和“备用 DNS”栏填入上面推荐的地址（例如阿里的 `223.5.5.5` 和 `223.6.6.6`）。
    - 点击 **“保存”**，并建议**重启路由器**使配置生效。

---

### 💻 方法二：在 Windows 电脑上修改（仅本机生效）

如果你不方便动路由器，或者只想优化这台电脑，可以按以下步骤操作（适用于 Win10/Win11）：

1. **打开网络连接面板**：
    - 按下键盘上的 `Win + R` 键，输入命令 `ncpa.cpl` 并回车。
    - 或者：右键点击任务栏右下角的网络图标 -> “网络和 Internet 设置” -> “更改适配器选项”。
2. **修改属性**：
    - 找到你正在使用的网络（Wi-Fi 或 以太网），**右键**点击它，选择 **“属性”**。
    - 在列表中找到并双击 **“Internet 协议版本 4 (TCP/IPv4)”**。
3. **填入 DNS**：
    - 选择 **“使用下面的 DNS 服务器地址”**。
    - 填入首选和备用 DNS（例如腾讯的 `119.29.29.29` 和 `182.254.116.116`）。
    - 点击 **“确定”** 保存。

---

### 📱 方法三：在手机 Wi-Fi 中修改（仅本机生效）

#### iPhone / iPad (iOS)

1. 进入 **“设置”** -> **“无线局域网”**。
2. 点击当前连接 Wi-Fi 右侧的蓝色 **“i”** 图标。
3. 向下滑动找到 **“配置 DNS”**，点击它。
4. 选择 **“手动”**，删除里面原有的服务器地址。
5. 点击 **“添加服务器”**，输入新的 DNS（如 `223.5.5.5`），点击 **“存储”**。

#### Android (安卓)

_不同品牌菜单略有差异，通常在 WLAN 设置中：_

1. 进入 **“设置”** -> **“WLAN”** (或 Wi-Fi)。
2. **长按**或点击当前连接的 Wi-Fi 名称，选择 **“修改网络”** 或 **“高级设置”**。
3. 将 IP 设置从“DHCP”改为 **“静态”**。
4. 在 **“DNS 1”** 和 **“DNS 2”** 栏中填入新的 DNS 地址，保存即可。

### ✅ 最后一步：验证是否生效

修改完成后，建议你刷新一下 DNS 缓存，确保新设置立即生效：

1. 按下 `Win + R`，输入 `cmd` 回车。
2. 在黑框中输入以下命令并回车：
   
    bash
    
    编辑
    
    ```
    ipconfig /flushdns
    ```
    
3. 看到“已成功刷新 DNS 解析缓存”后，你可以再次运行之前的 `nslookup bilibili.com`。
4. 如果显示的服务器地址变成了你刚才设置的（如 `223.5.5.5`），且不再提示“请求超时”，说明修改成功！
